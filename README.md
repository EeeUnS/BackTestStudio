## 실행

Node.js 24 이상이 필요합니다. 전역 패키지나 시스템 설정은 변경하지 않습니다.

```powershell
npm install
npm run dev
```

브라우저에서 http://127.0.0.1:5173 을 엽니다. 종료는 Ctrl+C입니다.

```powershell
npm test
npm run typecheck
npm run build
npm start
```

이 PC에서는 npm이 PATH에 없어 다음 절대 경로를 사용할 수 있습니다.

```powershell
& 'C:\Program Files\Microsoft Visual Studio\18\Community\MSBuild\Microsoft\VisualStudio\NodeJs\npm.cmd' run dev
```

## 현재 구현

- React + TypeScript + Vite, Node 로컬 API, Lightweight Charts 실제 가격 표시.
- 6종목 자동 조회, 파일 캐시, 데이터 버전·조회일·범위·경고·오래된 캐시 표시.
- OHLC·날짜·통화·거래량 검증, SHA-256 캐시 무결성 검사, 검증 후 파일 교체.
- 조회 실패 시 기존 정상 캐시 보존. 같은 종목 동시 조회 합치기. UI에서 이전 종목 응답 무시.
- 공통 계좌 원장, 일시불·주간/격주/월간 적립식 계산, XIRR·TWR·MDD·조건부 CAGR 구현.
- VR5.0 참고 재현: 기본/실력 체크박스·거치/적립/인출, 초기 배분·V/G/밴드·주기·Pool·별도 입출금과 미지급 인출,1주 사다리 그룹 체결을 실제 Worker에 연결합니다. **공식 원문 검증 미완료**입니다.
- V3.0 참고 재현: 전일 장부 LOC/목표 지정가, 원금 소진¼ MOC·쿼터, 양의 실현수익 재투입, 분할/목표/재투입/고정 가격 단위 설정·T/모드 상태. **공식 원문 검증 미완료**로 표시합니다.
- 분할수정 가격을 당시 1주 가격으로 복원하고, 사용자 요청에 따라 모든 분배금은 계산에서 제외합니다. 지급일 미확보로 차단하지 않습니다.
- Worker 실행, 최신 요청 우선, 100ms 연속 입력 합치기, 최근4건 결과 캐시. 종목 데이터 변경 시 Worker 종료. 실행 중 입력이 바뀌면 해당 Worker를 종료·교체하여 이전 동기 작업을 취소합니다. 완료된 Worker는 유지하며, 교체 때만 메모리 캐시가 초기화됩니다.
- 종료일만 연장하면 계좌·V3/VR 내부 상태에서 새 거래일만 추가 계산하고, 축소하면 저장된 일별 상태·거래·현금흐름으로 지표를 다시 산출합니다. 시작일/설정별 실행기는 최근4개로 제한합니다. 시작일 변경·데이터 교체·Worker 취소 교체는 새 계산입니다.
- 날짜·범위 슬라이더·빠른 기간·영역 이동으로 원장 재시작. 가격 차트 확대·이동은 계산 기간과 분리.
- 가격·자산·원화 차트의 조회일/커서 연동. 날짜 입력·포인터·거래 선택을 공통 계좌 조회일에 연결하며 주·월봉은 해당 날짜가 속한 봉을 가리킵니다.
- 금액/비중 전환: 주식·현금(잠금 포함)의 일별 비중과 선택 날짜 수치. 총자산0이면 비중 미산출.
- 성과·자산/주식/현금 곡선·날짜별 계좌·매매 마커·페이지별 거래 내역을 실제 결과에 연결.
- 일·주·월 봉, 현재 봉 기준 이평선5·20·60·120·200의 표시/기간/색상, 거래량·OHLC 조회, 봉별 거래 그룹 상세.
- 전체 이력 탐색 차트의 양끝 핸들과 선택 영역 이동. 포인터 드래그·방향키·날짜/슬라이더 입력을 함께 지원.
- 미국 종목의 원화 보고: 연준 H.10 공식 환율, 날짜별 실제 입출금 환산, 원화 TWR/MDD/XIRR·자산 곡선·환율 관측일 표시. USD 결과는 유지하며 TIGER는 중복 환산하지 않습니다.
- 자동 테스트64개, 개선 시안 회귀9개, 실제 Chrome·Worker 브라우저 통합15개 검증 그룹 통과.

현재 **일시불·적립식·V3/VR 참고 재현 백테스트를 화면에서 실행**할 수 있습니다. 실제 가격을 조회한 뒤 백테스트 시작을 누르면 최근5년(이력이 짧으면 가능한 전체 구간)을 계산하며 기간·투자 설정 변경 시 다시 계산합니다. 분배금은 제외합니다. V3·VR 공식 원문 대조, 추정 가격/비용 모델, 상세 가격 차트 위 기간 핸들·거래 손익 연결선·성과 비교·전체 성능 검증은 아직 남아 있습니다. 1차 완료 전 2차 구현으로 넘어가지 않습니다.

## 데이터 제한

Yahoo chart는 연구용 비공식 조회 어댑터입니다. 정식 공급 계약·이용 조건·기업행동 완전성 검증을 완료한 공급원으로 표시하지 않습니다. 가격은 분할수정 OHLC이며 총수익 adjclose는 사용하지 않습니다. 당시 정수주 체결에는 선택 종료일 이후 분할까지 포함해 단위를 복원합니다. 실제 분할 이력의 운용사 전수 대조는 남아 있습니다.

당일 봉은 완성 여부가 불명확하므로 제외합니다. OHLC 전체가 없는 행은 날짜별 경고로 남기며 임의 가격을 생성하지 않습니다. 거래소 달력 대조는 미완료입니다. **사용자 변경 지시: 분배금은 지급일 확보 여부와 관계없이 전부 무시합니다.** 분배금 입금·미수금·자동 재투자는 실제 앱 계산에 반영하지 않으며 지급일 누락으로 차단하지 않습니다. 원시 분배금 자료는 삭제하지 않습니다. 분배금을 제외하므로 결과는 분배금 포함 총수익이 아닙니다.

원화 보고는 연준 H.10의 거래일별 뉴욕 정오 관측 환율을 사용하는 사후 평가입니다. 주간 공표·수정 가능 자료이므로 당시 공개된 정보만 사용하는 환전 시뮬레이션이 아닙니다. 해당일 또는 이전 관측값만 적용하고 관측일·경과일을 표시합니다. 최초 환율 이전 구간은 원화 보고만 제공하지 않으며 USD 계산은 유지합니다. 환전 비용·세금은 제외합니다.

시세와 환율은 `cache/`에 저장되며 Git 대상에서 제외합니다. 입력·계산 결과용 DB/localStorage는 사용하지 않습니다. 서버는 127.0.0.1에만 바인딩됩니다.

## Browser integration tests

```powershell
npm run build
# 첫 터미널
npm start
# 다른 터미널
npm run test:browser
```

브라우저 테스트는 실제 Chrome·Web Worker를 쓰되 시세 API에 결정적 테스트 자료를 주입합니다. 실제 시세 공급원의 완전성 검증을 대신하지 않습니다. 캡처는 `work/`에 저장합니다. 결과에 표시되는 ms는 Worker 내부 계산 시간이며 데이터 적재·전송·렌더 시간은 제외합니다.

## GitHub Pages 정적 배포

Pages 빌드는 브라우저에서 배포된 JSON을 읽습니다. Node.js 24는 빌드와 예약 수집에 사용합니다.

```sh
npm ci
npm run build -- --mode pages --base /BacktestStudio/
node server/exportPages.ts refresh cache
```

저장소명에 맞춰 base 경로를 바꿉니다. 이미 확보한 전체 캐시로 외부 조회 없이 빌드 데이터를 만들 때는 refresh 대신 export를 사용합니다. 이 모드는 시세·참조 지수·환율 캐시가 모두 있어야 합니다.

GitHub의 Settings → Pages에서 GitHub Actions를 선택합니다. 배포할 데이터의 외부 공개 권한을 확인한 후 저장소 Actions 변수 BACKTEST_PAGES_ENABLED를 true로 설정합니다. 기본 브랜치의 워크플로가 한국시간 오전 9시 17분에 실행되며 Actions 화면에서 수동으로도 실행할 수 있습니다. 워크플로가 검증을 통과하여 배포한 캐시는 backtest-data 브랜치에 보관합니다. 공개 저장소에서 이 브랜치와 Pages의 JSON은 누구나 조회할 수 있습니다.

시세는 마지막 저장 거래일 이전 10일을 포함해 누락분과 최근 정정분을 병합합니다. 분할 이력이 달라지면 해당 종목의 전체 이력을 다시 가져옵니다. 분할 및 과거 정정 데이터를 전체 재검증하려면 새 캐시 경로에서 refresh를 실행할 수 있습니다. 보조 데이터는 기존 어댑터로 새로 읽으며 추정 모델은 입력 버전으로 재생성합니다. 필수 데이터 수집이나 검증에 실패한 실행은 새 사이트를 게시하기 전에 중단됩니다.
